# 🚀 SwingBy (스윙바이)

**SwingBy**는 궤도를 설계하고 퍼즐을 해결하는 우주 물리 퍼즐 게임입니다. (현재 개발 중인 프로토타입 버전입니다.)

## 🎮 게임 실행 방법
1. `Build` 폴더 내의 **`version0.1.1`** 폴더 안에 있는 모든 파일을 다운로드합니다.
2. `SwingBy.exe`를 실행합니다.
3. 터미널 창의 `>` 기호 뒤에 명령어를 입력하여 게임을 제어할 수 있습니다.
   - `/start`: 게임을 시작합니다.
   - `/next`: 스테이지 클리어 후 다음 스테이지로 이동합니다.
   - `/exit`: 게임을 종료합니다.

## 🕹️ 조작법 및 터미널 명령어
| 구분 | 입력 | 기능 |
| :--- | :--- | :--- |
| **이동/조작** | **W, S / A, D / Q, E** | 플레이어 캐릭터 회전 |
| **이동/조작** | **Spacebar** | 가속 (빨간색 돌출부 반대 방향 추진) |
| **카메라** | **C** | 카메라 모드 전환 (캐릭터 고정 ↔ 위치 고정) |
| **카메라** | **마우스 우클릭** | 카메라 고정 모드 시 주변 둘러보기 |
| **시스템** | **R** | 게임 중 터미널 화면으로 즉시 복귀 |
| **터미널** | **명령어 입력** | `/start`, `/next`, `/exit`, `/help` 등 사용 |

## 💡 게임 플레이 팁
- **목표**: 맵 어딘가에 위치한 거대한 핑크색 구체를 찾아 도착하면 게임이 종료됩니다.
- **스테이지 진행**: 스테이지를 클리어한 후에는 반드시 `/next` 명령어를 입력해야 다음 스테이지로 이동할 수 있습니다.
- **길 찾기**: 우측 상단의 `Distance` 수치를 확인하며 핑크색 구체와의 거리를 좁혀보세요.
- **터미널 스크롤**: 과거에는 터미널이 상단에 항상 고정되었으나 수정되었습니다. 스크롤을 내려 하단으로 이동할 수 있습니다. (단, 새로운 명령어를 입력할 때마다 다시 상단으로 고정되므로 필요시 스크롤을 내려 확인해 주세요.)
- **입력창 관리**: `/help` 입력 후 `>` 기호가 사라져도 입력창은 유지됩니다. 사라진 위치를 클릭하면 다시 입력을 이어갈 수 있습니다.

## ⚠️ 현재 상태 및 알려진 이슈
- **에셋(Asset) 미적용**: 현재 개발 초기 단계로, 대부분의 오브젝트가 회색 구체 형태로 표현됩니다.
- **성능**: 오브젝트가 많아 사양에 따라 다소 렉이 발생할 수 있습니다.
- **터미널 모드**: 게임 종료 또는 `R` 키 입력 시 터미널 환경으로 복귀합니다.

## 📅 업데이트 계획
- **스테이지 추가**: 현재 플레이 가능한 스테이지 외에, 더욱 복잡한 궤도 설계가 필요한 새로운 스테이지들이 지속적으로 업데이트될 예정입니다.
